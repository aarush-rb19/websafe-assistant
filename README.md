# WebSafe: Digital Security Assistant

**Live Demo:**

WebSafe is a responsive, client-side web application designed to audit and guide students on their personal digital security habits. Built during the final round of the Kindle Junior 5.0 hackathon (Top 20 Finalist out of 200+ participants).

## Features

* **Real-time Password Analysis:** An interactive strength meter that dynamically validates passwords against seven distinct rules, including character diversity, length requirements, and a blacklist of common vulnerable passwords.
* **Diagnostic Security Quiz:** A quick-check assessment covering password reuse, Multi-Factor Authentication (MFA), and device locks. The logic calculates a security score and automatically highlights the specific area where the user needs the most improvement.
* **Actionable Best Practices:** An interactive UI accordion categorizing security habits across six domains: Password security, MFA, Device security, Privacy settings, Social media safety, and Account protection.
* **Gamified Progress Tracking:** Checklists embedded within the educational accordions that mathematically update a global "Security Habit Progress" bar as the user completes actionable security tasks.

## Tech Stack

* **HTML5:** Semantic structure and accessible form elements.
* **CSS3:** Custom variables, responsive layouts, state-driven animations, and inline SVG illustrations.
* **JavaScript (Vanilla):** DOM manipulation, event-driven validation, and state management without external libraries.
